# Ayo Web

A modern browser-based card game inspired by the classic UNO experience.

Built with HTML, CSS, and JavaScript, Ayo Web features responsive gameplay, AI bots, smooth animations, and a clean modern interface that works on both desktop and mobile devices.

## Project Structure

```
Ayo-Web/
├── app.js            # Game logic
├── style.css         # Stylesheets
├── index.html        # Main page
├── web_launcher.bat  # Starts the local server
└── README.md
```

## Installation

```bash
git clone https://github.com/<ardaylmz30>/AYO-Web.git
cd AYO-Web
```

Then run `web-launcher.bat` (Windows) or serve the folder with any static file
server, e.g.:

```bash
python3 -m http.server 8001
```
